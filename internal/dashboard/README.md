# Дашборд SAR-Дозор

Из корня проекта запустите API:

```bash
go run ./cmd/api
```

Откройте **http://localhost:8080/**. Если API уже был запущен до добавления
дашборда, остановите его через Ctrl+C и запустите снова.

Нужны работающая PostgreSQL, актуальная схема и `DATABASE_URL` в `.env`.
Дашборд использует `GET /objects` и `GET /objects/{id}/measurements`.
HTML, CSS и JavaScript встроены в Go-приложение через `embed`:
дополнительные установки и сборка фронтенда не нужны.

## Что отображается

- Выбор объекта и его параметры.
- Карта OpenStreetMap (для карты нужен интернет); координаты берутся из объекта.
- Смещение **за интервал пары снимков**, отдельно для каждого метода опоры.
- Когерентность участка дамбы, таблица измерений, фильтры и выгрузка выбранных
  измерений в JSON. Даты фильтруются по второму снимку пары, включительно.
- Средняя когерентность: сначала среднее по выбранным измерениям каждой задачи,
  затем среднее по задачам. Это не даёт парам с большим числом методов больший вес.
- Максимальное абсолютное смещение считается по выбранным измерениям.

Наведите курсор на точку графика или перейдите к ней клавишей Tab для подробностей.
Все численные значения также доступны в таблице. Пустая выборка не подменяется
нулевыми измерениями. Риск-рейтинг и накопленное смещение не рассчитываются.

## Файлы и проверки

- `static/index.html` — структура страницы.
- `static/styles.css` — оформление и адаптация к узким экранам.
- `static/app.js` — запросы, графики, фильтры, таблица и карта.
- `static/data.mjs` — фильтрация и расчёт сводки.
- `dashboard.go` — раздача файлов через Go.

```bash
go test ./internal/dashboard ./cmd/api
node --test internal/dashboard/data_test.mjs
```

Node.js нужен только для запуска тестов расчётов, не для работы дашборда.
